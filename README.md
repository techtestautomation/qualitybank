# QualityBank

QualityBank is a realistic banking demo application built as a Quality Engineering reference project.

It is designed to demonstrate:

- modern Playwright + TypeScript automation
- UI and API testing
- deterministic test data
- CI/CD quality gates
- testability-focused application design
- AI-assisted failure analysis in later phases

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- PostgreSQL 17
- Prisma 7
- Docker
- pnpm
